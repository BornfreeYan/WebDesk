# WebDesk 用户故事

按角色与优先级分层，MVP 为最小可用版本，v1 为完整体验，扩展为后续迭代。

---

## 一、终端用户故事（使用 WebDesk 的人）

### MVP — 本地桌面书签管理

**US-001** 作为用户，我打开页面后能看到一个类似 macOS 桌面的界面，有壁纸、可拖拽的图标网格和底部 Dock 栏，这样我能直观理解这是我的个人桌面。

**US-002** 作为用户，我点击桌面上的任意图标后，浏览器会在新标签页打开对应的网站，这样我能快速访问常用站点。

**US-003** 作为用户，我可以通过设置面板修改界面的亮暗模式和主题色，这样我能把桌面调成自己喜欢的风格。

**US-004** 作为用户，我点击 Dock 栏中的"设置"图标后，会打开一个小型浮动设置窗口（约占屏幕 1/6，左上角有绿黄红三个 macOS 风格按钮），这样我能调整个人偏好而不离开当前桌面。

**US-005** 作为用户，我可以拖拽桌面图标到任意位置，这样我能按自己的习惯整理桌面布局。

**US-006** 作为用户，我可以手动添加、删除、编辑桌面上的书签图标（名称和 URL），这样我能管理自己的常用网站。

**US-007** 作为用户，我可以从浏览器导出的 HTML 书签文件中批量导入书签，这样我能把现有书签快速迁移到 WebDesk。

**US-008** 作为用户，我刷新页面或关闭浏览器后再打开，桌面图标和布局仍然保持，这样我的整理不会丢失。

### v1 — 跨设备同步与增强体验

**US-009** 作为用户，我可以在设置中配置我的 GitHub Personal Access Token 和仓库信息，这样 WebDesk 能把我的书签数据同步到我的 GitHub 仓库。

**US-010** 作为用户，我在 A 电脑整理好的书签和布局，在 B 电脑上登录同一个 GitHub 账号后能自动恢复，这样我能跨设备使用同一套桌面。

**US-011** 作为用户，我可以在桌面空白处右键（或等效操作）唤起快捷菜单，进行添加书签、整理布局等操作，这样操作效率更高。

**US-012** 作为用户，书签图标能自动显示对应网站的 favicon，这样我能通过视觉快速辨认不同网站。

### 扩展 — 本地轻量应用（可选）

**US-013** 作为用户，我可以在桌面上打开一个便签应用，记录临时文字，数据保存在本地，这样我能替代桌面的 TXT 文件。

**US-014** 作为用户，我可以使用一个简单的番茄钟或计时器工具，帮助我专注工作。

---

## 二、开发者故事（Fork 仓库部署的人）

**DS-001** 作为开发者，我可以通过 Fork 原始仓库并启用 GitHub Pages，在 5 分钟内部署一个属于自己的 WebDesk 实例，无需购买服务器。

**DS-002** 作为开发者，我可以通过修改配置文件（或前端界面）自定义默认壁纸、主题色和预置书签，这样我能让 WebDesk 体现个人风格。

**DS-003** 作为开发者，我填写的 GitHub Token 仅需要 `public_repo` 最小权限，这样我的账号安全不会受到威胁。

## 三、验收标准汇总

| 故事 | 验收标准（ Definition of Done ）|
|---|---|
| US-001 | 页面加载后渲染壁纸 + 图标网格 + Dock；图标从数据文件/localStorage 读取 |
| US-002 | 点击图标触发 `window.open(url, '_blank')`，无站内 iframe/嵌套 |
| US-003 | 设置切换后，整个界面主题即时生效；偏好持久化到 localStorage |
| US-004 | 设置窗口为浮动卡片，可拖拽标题栏；三按钮中至少"关闭"可用 |
| US-005 | 拖拽后图标位置即时更新；刷新页面后位置保持 |
| US-006 | 提供添加/编辑/删除入口；表单校验 URL 格式；即时生效 |
| US-007 | 支持上传 `.html` 文件；解析后生成图标列表；用户可确认导入范围 |
| US-008 | 所有数据默认持久化到 localStorage；加载时优先读取 localStorage |
| US-009 | 设置面板提供 Token + Owner + Repo + Branch 输入；保存后测试连通性；支持手动"立即同步" |
| US-010 | 页面加载时自动拉取云端数据；云端更新则提示加载，本地更新则自动推送（debounce 5s）；同步文件为仓库根目录 `webdesk-data.json`，含 `updatedAt` 时间戳 |
| US-012 | 图标默认尝试加载 `https://www.google.com/s2/favicons?domain=url`；失败时显示默认占位图标 |
| US-015 | 桌面时钟：毛玻璃卡片显示时间/日期；可拖拽；位置持久化；设置中可启用/禁用 |
| US-016 | 桌面待办：毛玻璃卡片，支持添加/删除/勾选；可拖拽；内容与位置持久化；设置中可启用/禁用 |
| US-017 | 全局搜索：右上角搜索框，模糊匹配所有层级书签/文件夹；点击书签打开链接、点击文件夹打开窗口；Esc/失焦关闭 |
| US-018 | 图标 hover 删除按钮：灰色常态、hover 变红（不再常驻红色） |
